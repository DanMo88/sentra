# Sentra (sample)

American English sentence by sentence for Persian speakers (A1–C2). Sample: A1 Lesson 1 (25 sentences), placement test, six modes.

- Content: `content/*.txt` → `python3 tools/build.py` → `js/data.js`
- Audio: `python3 tools/tts.py` (edge-tts: AriaNeural / AndrewNeural alternating, words AriaNeural), silence-trimmed by `tools/trim.py`
